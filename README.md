## Quick Start

### Prerequisites
- Node.js 18+

Clone with submodules

    git clone --recurse-submodules https://github.com/wisebreeze/cv.git
    cd cv

Install dependencies

    npm install

Start development  
\* Local website: [localhost:8080](http://localhost:8080/)

    npm start

Building

    npm run build
