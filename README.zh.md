## 快速开始

### 环境要求
- Node.js 20.19+（或 22.12+）

克隆仓库（包含子模块）

    git clone --recurse-submodules https://github.com/wisebreeze/cv.git
    cd cv

安装依赖

    npm install

启动开发服务器  
\* 本地访问: [localhost:8080](http://localhost:8080/)

    npm run dev

构建项目

    npm run build
