## 快速开始

### 环境要求
- Node.js 18+

克隆仓库（包含子模块）

    git clone --recurse-submodules https://github.com/wisebreeze/cv.git
    cd cv

安装依赖

    npm install

启动开发服务器  
\* 本地访问: [localhost:8080](http://localhost:8080/)

    npm start

构建项目

    npm run build

## 贡献指南
1. Fork 仓库并创建特性分支
2. 遵循编码规范：
   ```editorconfig
   [*.{js,ts,vue}]
   indent_style = space
   indent_size = 2
   ```
3. 提交格式规范的 PR：
   `简要描述`
